# Portfolio 4 — NoSQL and Advanced Data Models (7 marks)

## Aim
Model a student's academic summary as a flexible document and compare it with the normalised relational design.

This starter includes JSON document examples. MySQL supports JSON data, but MySQL JSON is not a separate NoSQL database. To demonstrate an actual NoSQL implementation, you may additionally use MongoDB Community or MongoDB Atlas if your lecturer expects a separate NoSQL engine.

## Steps
1. Review `student_academic_document.json`.
2. Run `01_mysql_json_demo.sql` to show document-style JSON storage/querying within MySQL.
3. If required, import the JSON into MongoDB and capture screenshots of the document and a query.
4. Use `model_comparison.md` to explain where document storage is useful and what it does not replace.
