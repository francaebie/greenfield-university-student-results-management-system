# MIT 8103 ADVANCED DATABASE SYSTEMS PORTFOLIO

## Greenfield University Student Results Management System

**Course:** MIT 8103 – Advanced Database Systems  
**Student:** Franca Ebie  
**Institution:** Greenfield University (Case Study)

## 1. Project Overview

This portfolio presents the design and development of a Student Results Management System for Greenfield University. The project demonstrates the application of advanced database concepts in managing student information, academic records and examination results.

## 2. Portfolio Contents

### Portfolio 1: Database Design
Covers the case study, entity relationship diagram (ERD), relational schema, primary keys, foreign keys, constraints and database normalisation.

### Portfolio 2: Query Processing and Optimisation
Demonstrates SQL queries, query execution plans, indexing and query performance analysis.

### Portfolio 3: Transactions and Concurrency
Explores database transactions, COMMIT, ROLLBACK, transaction isolation and concurrency management.

### Portfolio 4: NoSQL Databases
Explores a MongoDB document-based approach to storing student information and academic results.

### Portfolio 5: Distributed and Cloud Databases
Presents a proposed distributed and cloud database architecture, including replication, sharding, availability and scalability.

## 3. Technologies and Tools

- MySQL
- MySQL Workbench
- MongoDB (proposed NoSQL implementation)
- GitHub
- SQL

## 4. Learning Outcomes

The project provides practical exposure to database design, query optimisation, transaction management, NoSQL data modelling and distributed database concepts.

## 5. Conclusion

The project demonstrates how database technologies and advanced database management concepts can support the effective management of university student records and academic results.
