# Portfolio 1 — Database Design and Modelling (7 marks)

## Aim
Design a relational database for Greenfield University's student results process.

## Files
- `01_schema.sql`: creates the database and six related tables.
- `02_seed_data.sql`: inserts fictional sample records.
- `03_validation_queries.sql`: checks that the tables and sample data work.
- `ERD.md`: relationship description for drawing an ER diagram.
- `normalisation.md`: explanation of keys and normalisation.

## Steps
1. Run `01_schema.sql`.
2. Run `02_seed_data.sql`.
3. Run `03_validation_queries.sql`.
4. Inspect the tables in MySQL Workbench.
5. Create an ER diagram using Workbench: Database > Reverse Engineer, select `greenfield_university`, then finish the wizard.
6. Save an ER diagram screenshot or export it as an image into this folder.
7. Write a short reflection in your own words about the design choices and any errors you corrected.
